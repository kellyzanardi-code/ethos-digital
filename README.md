# Ethos Digital

Create a modern, professional, high-converting website for Ethos Cursos, a technology and digital education company that provides professional websites and strategic social media content for businesses, while preparing to launch online technology courses.

Brand Identity and Visual Direction

Use a sophisticated visual identity inspired by the Ethos brand:

Deep navy blue: #1D2E45

Ethos orange: #F2721C

Off-white: #F7F5F2

Charcoal: #17212B

Optional complementary accents used sparingly: muted teal #2E8C8C and soft golden yellow #F5B942

The design should feel modern, credible, intelligent, creative, and trustworthy. Use navy as the main foundation, orange for highlights and calls to action, and off-white sections to create visual breathing room. Use teal or golden yellow only as subtle secondary accents. Avoid excessive gradients, excessive neon, visual clutter, overly rounded cards, and generic startup aesthetics.

Use a clean, premium sans-serif typography system with strong hierarchy. Headlines should be bold and memorable, body text should be highly readable, and buttons should have clear contrast. Use subtle motion effects, smooth scrolling, elegant hover states, and restrained animations.

Website Goal

The primary goal is to:

Present Ethos Cursos as a reliable technology and digital education company.

Clearly promote its current services.

Generate leads from businesses interested in professional websites and social media content.

Build anticipation for the upcoming technology courses.

Encourage visitors to contact Ethos Cursos.

Recommended Website Structure

Create a responsive single-page website with a clear navigation bar and the following sections:

1. Header and Navigation

Create a sticky, responsive navigation bar containing:

Ethos Cursos logo

Home

Services

How It Works

Upcoming Courses

About Ethos

Contact

Include a highly visible CTA button:

Contact Ethos

On mobile, use a clean hamburger menu. Keep the navigation simple and easy to scan.

2. Hero Section

Create a visually impressive hero section with a dark navy background, refined orange accents, subtle digital network elements, and an elegant technology-inspired composition.

Use this headline:

Use this supporting text:

Ethos Cursos creates professional websites, strategic social media content, and practical technology education to help businesses become more visible, credible, and competitive.

Include two CTA buttons:

Talk to Ethos

Add a subtle visual representation of a modern website interface, digital strategy, or connected business ecosystem. Avoid generic stock photography. Use abstract technology elements, interface previews, or polished browser mockups instead.

Use elegant icons or minimal illustrations related to websites, content strategy, communication, and digital growth.

4. Value Proposition Section

Create a visually strong section with the headline:

Your Business Deserves to Be Found, Remembered, and Chosen.

Add this supporting text:

A good service is only part of the journey. Your business also needs a digital presence that communicates value, builds trust, and makes it easier for customers to choose you.

Credibility — Look professional from the first impression.

Visibility — Make it easier for customers to find your business.

Use orange highlights and subtle visual emphasis without making the section overly busy.

Grow

Use a clean timeline or horizontal step layout on desktop and a vertical timeline on mobile.

Conversion and UX Requirements

Use clear CTA buttons throughout the page.

Repeat the primary CTA strategically without overusing it.

Maintain excellent contrast and accessibility.

Use semantic HTML and accessible labels.

Ensure keyboard navigation works properly.

Include visible focus states.

Optimize for mobile, tablet, and desktop.

Make all text readable without excessive scrolling.

Keep important content within comfortable visual margins.

Use sticky navigation with smooth scrolling.

Add subtle entrance animations, but respect reduced-motion preferences.

Optimize image loading and performance.

Use optimized assets and lazy loading where appropriate.

Include SEO-friendly page metadata, title, description, Open Graph tags, and structured headings.

Use Portuguese as the website’s visible content language, even though this prompt is written in English.

Keep the tone professional, warm, direct, and confident.

Do not use exaggerated claims such as “guaranteed results” or “the best company.”

Do not invent client results, statistics, testimonials, certifications, awards, or contact details.

Technical Requirements

Build the website with a clean, maintainable structure using modern frontend best practices. Use reusable components for:

Navigation

Buttons

Service cards

Course cards

Process steps

Contact form

Footer

Ensure the final website is visually polished, responsive, accessible, fast, and ready for future integration with a CMS, email service, WhatsApp, analytics, and course enrollment system.
